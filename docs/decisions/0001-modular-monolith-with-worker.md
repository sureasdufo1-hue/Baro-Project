# ADR-0001: 모듈러 모놀리스와 비동기 워커

- 상태: 승인된 설계 기준 반영
- 기준일: 2026-08-18

## 배경

MVP는 계약, 약관, 문서, Fact, 판단, 계산, Evidence가 긴밀하게 연결됩니다. 동시에 OCR과 AI 추출처럼 오래 걸리는 작업은 HTTP 요청에서 분리해야 합니다.

## 결정

초기 시스템은 도메인 경계를 보존하는 모듈러 모놀리스로 구현하고 OCR, AI 추출, 약관 수집, 인덱싱, 알림은 비동기 워커에서 처리합니다.

## 결과

- 단일 배포 단위 안에서도 도메인 소유권과 인터페이스를 분리합니다.
- 비동기 작업은 상태, 제한된 재시도, 실패 원인을 기록합니다.
- 확장 가능성을 이유로 MVP 단계에서 임의로 마이크로서비스를 도입하지 않습니다.
