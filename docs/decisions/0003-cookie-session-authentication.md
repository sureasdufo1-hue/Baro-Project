# ADR-0003: HttpOnly 쿠키 기반 세션 토큰

- 상태: 승인
- 기준일: 2026-08-18

## 결정

API가 서명·만료된 세션 토큰을 발급하고 브라우저는 이를 HttpOnly, SameSite 쿠키로 보관합니다. 운영환경에서는 Secure 옵션을 강제할 수 있게 구성합니다.

## 이유

인증 토큰을 장기적으로 `localStorage`에 보관하지 않으며, 사용자 웹과 관리자 웹에서 같은 인증 기반을 사용할 수 있습니다.

## 후속 검토

Production 배포 전 키 회전, CSRF 방어 방식, 세션 폐기 목록, Refresh 정책, MFA를 확정해야 합니다.
